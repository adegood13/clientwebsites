# Daphne's Pet Grooming & Boarding — mockup site

Client-review mockup for **Daphne's Pet Grooming & Boarding** (3566 Walker Ave, Memphis TN). Owner-operated by Veronica Saulsberry.

Static HTML/CSS/JS, no build step.

## Pages

| File | Purpose |
| --- | --- |
| `index.html` | Marketing page · grooming, boarding, owner story, FAQ |
| `booking.html` | 5-step flow with auto-calculated estimate |
| `checkout.html` | Simulated $15 grooming / $25 boarding deposit |
| `confirmation.html` | Success + `.ics` |

## Deploy

Push to GitHub, connect to Netlify, publish dir = `.`. No build needed.

All bookings/payments are **simulated**. See `RESEARCH_NOTES.md`.
