# Amanda Rachael Photography — mockup site

Client-review mockup for **Amanda Rachael Photography** (1913 Huguenot Rd, Suite 100, North Chesterfield VA). Maternity / newborn / baby / cake-smash specialty.

Static HTML/CSS/JS, no build step. Open `index.html` to preview locally.

## Pages

| File | Purpose |
| --- | --- |
| `index.html` | Marketing page · portfolio (5 tabs), sessions, about, flow, reviews, FAQ, studio info |
| `booking.html` | 4-step flow (session, date, about you, confirm) |
| `checkout.html` | Simulated retainer payment (varies by session) |
| `confirmation.html` | Success page + `.ics` download |

## Deploy

Push branch to GitHub, connect to Netlify, publish dir = `.`. No build needed.

## Demo notice

All bookings/payments are **simulated** — nothing transmitted. Every footer carries a "DEMO MOCK-UP" badge.

See `RESEARCH_NOTES.md` for what's verified vs. placeholder.
