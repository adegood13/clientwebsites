# Golden Auto Detailing — mockup site

Client-review mockup for **Golden Auto Detailing** (Lincoln, NE). Mobile detailer.

Static HTML/CSS/JS, no build step. Open `index.html` to preview locally.

## Pages

| File | Purpose |
| --- | --- |
| `index.html` | Marketing page · packages, before/after, service area, FAQ |
| `booking.html` | 5-step booking (package, vehicle + add-ons, date/time, address+you, confirm) |
| `checkout.html` | Simulated $25 deposit form |
| `confirmation.html` | Success page with `.ics` download |

## Deploy

Push branch to GitHub, connect to Netlify, publish dir = `.`. No build needed.

## Demo notice

All bookings/payments are **simulated** — nothing leaves the browser. Every footer carries a "DEMO MOCK-UP" badge.

See `RESEARCH_NOTES.md` for what's verified vs. placeholder.
