# Mobile Detail AZ — mockup site

Client-review mockup for **Mobile Detail AZ LLC** (Tolleson, AZ — Phoenix Valley). DOT-registered mobile detailer.

Static HTML/CSS/JS, no build step.

## Pages

| File | Purpose |
| --- | --- |
| `index.html` | Marketing page · packages, before/after, service area, FAQ |
| `booking.html` | 5-step booking (package, vehicle + add-ons, date, where, confirm) |
| `checkout.html` | Simulated $25 deposit |
| `confirmation.html` | Success + `.ics` |

## Deploy

Push to GitHub, connect to Netlify, publish dir = `.`. No build needed.

All bookings/payments are **simulated**. See `RESEARCH_NOTES.md`.
