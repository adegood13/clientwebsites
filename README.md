# Platinum Salon — mockup site

Client-review mockup for **Platinum Salon** (20304 Trout Creek Dr, Tampa FL 33647). Co-owned by master colorist Allen Coleman and former occupational therapist Michael Berthelette.

Static HTML/CSS/JS, no build step.

## Pages

| File | Purpose |
| --- | --- |
| `index.html` | Marketing page · service menu (5 tabs), team, gallery, owner story, FAQ-free condensed flow |
| `booking.html` | 5-step booking with auto-suggested deposit |
| `checkout.html` | Simulated $25 deposit |
| `confirmation.html` | Success + `.ics` |

## Deploy

Push to GitHub, connect to Netlify, publish dir = `.`. No build needed.

All bookings/payments are **simulated**. See `RESEARCH_NOTES.md`.
