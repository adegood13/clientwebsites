# Purrfect Cleaning Co — mockup site

Client-review mockup for **Purrfect Cleaning Co** (Cincinnati, OH). Owner-operated by Ms. Natalie Poe.

Static HTML/CSS/JS, no build step.

## Pages

| File | Purpose |
| --- | --- |
| `index.html` | Marketing page · services, owner story, FAQ, trust strip |
| `booking.html` | 6-step flow with built-in instant quote calculator |
| `checkout.html` | Simulated card-on-file (charged after each visit) |
| `confirmation.html` | Success + `.ics` |

## Deploy

Push to GitHub, connect to Netlify, publish dir = `.`. No build needed.

All bookings/payments are **simulated**. See `RESEARCH_NOTES.md`.
